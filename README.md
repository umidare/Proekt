# Green World — beginner web project

A small responsive nature website built with plain HTML, CSS and JavaScript.

## How to open
1. Extract the ZIP file.
2. Open the `nature_web_project` folder.
3. Double-click `index.html` to open it in a browser.

You can also open the folder in VS Code and use the Live Server extension.

## Project files
- `index.html` — page structure and content
- `style.css` — colors, layout, responsive design and hover effects
- `script.js` — mobile menu, current year and demo contact form
- `assets/` — local landscape images and a short nature video

## Beginner practice ideas
1. Change the website title and paragraph text.
2. Change the main colors in `:root` inside `style.css`.
3. Add a fourth image card in the gallery.
4. Add a new section called “How to protect nature”.
5. Change the form confirmation message in `script.js`.

The contact form is front-end only: it does not send messages to an email address or server.
